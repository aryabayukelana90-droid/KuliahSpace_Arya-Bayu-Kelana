Tujuan

Membantu mahasiswa mengelola materi, tugas, mata kuliah, dan tenggat dalam satu antarmuka yang mudah dipahami.

🧩

Fitur inti

Dashboard, pencatatan materi, pencatatan tugas, pencarian, filter status, serta ekspor cadangan data.

🌐

Publikasi online

File statis HTML, CSS, dan JavaScript dapat dipublikasikan melalui layanan hosting statis seperti GitHub Pages.

🔒

Batasan saat ini

Belum ada login atau database cloud. Data hanya berada di browser ini; pengguna berbeda atau perangkat lain tidak berbagi data otomatis.

Pencadangan dan data

Kontrol pengguna

Ekspor file JSON secara berkala untuk menyimpan cadangan data. Impor cadangan dapat memulihkan data pada browser ini. Menghapus data bersifat permanen untuk penyimpanan lokal yang sedang digunakan.
