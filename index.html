Tentang KuliahSpace

Website untuk mengelola beberapa mata kuliah, beserta materi dan tugas yang terhubung dengan masing-masing mata kuliah.

🎯

Tujuan

Membantu mahasiswa mengelola berbagai mata kuliah dalam satu website, dengan materi dan tugas yang terpisah per mata kuliah.

🧩

Fitur inti

Tambah dan cari mata kuliah, ruang per mata kuliah, pengelolaan materi, daftar tugas, tenggat, status tugas, dan lampiran file materi/tugas.

🌐

Publikasi online

Website statis HTML, CSS, dan JavaScript dipublikasikan melalui GitHub Pages.

🔒

Penyimpanan data

Data mata kuliah, materi, dan tugas disimpan pada browser yang digunakan. Data tidak otomatis tersinkron ke perangkat dosen atau perangkat lain.

Pencadangan data

Kontrol pengguna

Ekspor data sebagai file JSON untuk menyimpan cadangan. Impor cadangan memulihkan data dan menyinkronkannya ke cloud setelah login. Untuk sinkronisasi lintas perangkat, jalankan file SQL setup yang disediakan di Supabase SQL Editor.
